Burrow: File Manager

## Full description (max 4000)
Burrow is a fast, good-looking file manager that keeps everything on your phone and nothing in the cloud.

SEE WHAT FILLS YOUR PHONE
A glass storage tube shows how full your phone is and what fills it: videos, images, audio, documents, apps, archives, and the system.

EXPLORE YOUR BURROW
Tap the tube to dig in. Every kind of file gets its own underground chamber, sized by how much space it takes. Tap a chamber to see its files and clean up.

BROWSE EVERYTHING
• Your whole internal storage and SD cards
• Breadcrumb navigation, list or grid view
• Sort by name, date, size or type
• Show or hide hidden files
• Long-press to select many files, then copy, move or delete them
• New folder, rename and file details

FIND ANY FILE
Search every file on your device by name, then narrow it down by type, size or date.

OPEN FILES RIGHT INSIDE THE APP
• PDF viewer with zoom, page navigation and password-protected PDFs
• Image gallery: swipe between photos, double-tap to zoom
• Video player with seek, playback speed and fullscreen
• Music player for MP3, FLAC, M4A, OGG and more: skip tracks, and it keeps playing with the screen off
• Text and code viewer for TXT, JSON, CSV, Markdown, logs and more
• Archive viewer for ZIP, TAR, GZ, BZ2 and XZ. Extract them with one tap
• Everything else opens in the app of your choice

INSTALL APKS
Tap an APK file to install it through Android's system installer.

MAKE IT YOURS
Light, dark or system theme, and a choice of accent colors.

PRIVATE BY DESIGN
Burrow has no internet permission. It has no accounts, no ads, no analytics and no tracking. Your files never leave your device.

Why Burrow asks for "All files access": a file manager needs it to show, open and organize the files across your storage. Burrow uses it only to do what you ask.
